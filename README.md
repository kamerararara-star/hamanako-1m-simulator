# 浜名湖 1M展開シミュレーター

Streamlitで動く、1M（第1ターンマーク）の簡易展開シミュレーターです。

## 起動
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud
GitHubリポジトリのルートに `app.py` と `requirements.txt` を置いて、
Streamlit Community Cloudから `app.py` をEntrypointとしてデプロイします。

※現在は試作モデル。過去の浜名湖データを学習させる前提です。
